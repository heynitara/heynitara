# HeyNitara — SEO Ready Package

Domain: https://heynitara.my.id/

## Isi paket
- index.html (sudah dilengkapi meta SEO, Open Graph, Twitter Card, JSON-LD)
- robots.txt
- sitemap.xml
- favicon.svg
- og-image.png (1200x630)
- style.css, script.js
- PANDUAN-SEO-LENGKAP.md (ikuti panduan ini)

## Cara pakai
1. Upload semua file ke root repo GitHub (sama level dengan index.html).
2. Commit & push ke branch yang dipakai GitHub Pages.
3. Ikuti langkah di PANDUAN-SEO-LENGKAP.md (Search Console, Bing, dll).

Lihat PANDUAN-SEO-LENGKAP.md untuk detail lengkap.
